# Release Notes - v2.0.0 (OpenApex AI)

**Release Date:** August 2026

## Overview
Version 2.0.0 marks the evolution from the old "F1 Setups Assist" into **OpenApex AI**. The project has shifted from being a simple XML setup formatter to a comprehensive, open-source AI Race Engineer.

In this release, we introduce live UDP telemetry reading (F1 24 and F1 25), Cyberpunk-themed UI, internationalization support, and two powerful transparent overlays ("HUDs") that float over your game without interrupting your gameplay.

## 🚀 New Features
- **Live Setups HUD:** Automatically displays the current setup of the track you're playing on as soon as you leave the pits.
- **Mathematical Tyre Predictor (AI):** Gathers real-time tyre-by-tyre degradation, estimates future wear based on wear history, and suggests optimal pit stops.
- **Multi-language Support (i18n):** The system now dynamically supports English, Portuguese, Spanish, German, Hindi, and Arabic, covering the largest racing audiences worldwide.
- **Cyberpunk UI Theme:** The entire settings interface has been redesigned using a modern Cyberpunk design token set (Neon/Magenta/Cyan).

## 🛠️ Technical Improvements
- **Windows Focus Stealing Fix:** The tyre overlay now utilizes an advanced `geometry(+-10000)` system to hide/show off-screen instead of traditional `withdraw()` / `deiconify()`. This completely prevents the HUD from stealing the OS window focus and minimizing the game.
- **Flexible Hotkeys:** The Tyre HUD toggle hotkey (default `F8`) can now be fully customized through the UI, making it easier to map to racing wheels and pedals.
- **F1 24/25 UDP Offset Fix:** The telemetry packet listener has been updated to reflect the increased byte size per lap (Lap reading from byte 33, LapDistance from byte 20).

## ⚠️ Known Issues
- No major bugs identified. In rare cases, telemetry may take 1-2 laps to properly calibrate the exact wear prediction average.
