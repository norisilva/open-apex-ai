Arquitetura Central

Dual-Scraper Fallback

Extrai setups do F1Laps de forma inteligente. Se bloqueado pelo Cloudflare, alterna automaticamente para o SimRacingSetup.com.

Perfis Dinâmicos

Escolha entre Esports (Cru), Gamepad (Estável) ou Acessibilidade (Distonia Focal) para transformar as restrições de suspensão e diferencial instantaneamente.

Overlay de Telemetria UDP

Detecta em qual pista você está correndo via telemetria UDP do Codemasters e exibe um overlay flutuante transparente com o setup customizado.

Como Começar

1

Baixe o App

Clique no botão de download acima ou vá até a aba Releases do GitHub e baixe o F1SetupsAssist.exe.

2

Execute o Arquivo

Coloque o arquivo F1SetupsAssist.exe baixado em qualquer lugar do seu PC e dê um duplo clique. Nenhuma instalação é necessária.

3

Jogue!

Use os controles do Painel para ajustar a rigidez da suspensão e clique em "Iniciar HUD". Certifique-se de que o aplicativo oficial do F1Laps esteja fechado para liberar a porta UDP 20777.
