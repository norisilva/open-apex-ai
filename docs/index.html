Core Architecture

Dual-Scraper Fallback

Intelligently scrapes setups from F1Laps. If blocked by Cloudflare, it seamlessly falls back to SimRacingSetup.com.

Dynamic Profiles

Choose from Esports (Raw), Gamepad (Stable), or Accessibility (Focal Dystonia) to instantly transform suspension and differential constraints.

UDP Telemetry Overlay

Detects the track you're currently racing via live Codemasters UDP telemetry and displays a floating, transparent overlay with the customized setup.

Getting Started

1

Download the App

Click the download button above or go to the GitHub Releases page to download F1SetupsAssist.exe.

2

Run the Executable

Place the downloaded F1SetupsAssist.exe anywhere on your PC and double click it. No installation needed.

3

Play!

Use the Control Panel sliders to adjust your suspension stiffness and hit "Start HUD". Make sure the official F1Laps App is closed to free up UDP port 20777.
