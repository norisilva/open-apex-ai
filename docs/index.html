Next-Gen Telemetry Features

🧠

Smart Tyre Predictor

Real-time degradation tracking using mathematical wear predictions to estimate optimal pit stop windows based on your driving style.

🏎️

Live Setup Overlay

Automatically detects the current track and displays your predefined setup directly on your screen as a transparent HUD.

🛡️

Zero Focus Stealing

Advanced OS-level geometry manipulation ensures that overlays appear without ever minimizing or stealing focus from your game.

⚙️

Accessibility Transformer

Tweaks the game's hardware XML configuration files dynamically to provide maximum stability for controller and gamepad players.

Built by the Community, for the Community
