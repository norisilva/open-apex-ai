Core Architecture

Dual-Scraper Fallback

Intelligently scrapes setups from F1Laps. If blocked by Cloudflare, it seamlessly falls back to SimRacingSetup.com.

Accessibility Engine

Applies a mathematical transformation layer that reduces suspension stiffness by 25% and adjusts differential constraints for gamepad users.

UDP Telemetry Overlay

Detects the track you're currently racing via live Codemasters UDP telemetry and displays a floating, transparent overlay with the customized setup.

Getting Started

1

Clone the Repository

git clone https://github.com/norisilva/f1-setups-assist.git
2

Install Dependencies

pip install -r requirements.txt
playwright install chromium
3

Run the App

Make sure the official F1Laps App is closed to free up UDP port 20777.

python main.py
